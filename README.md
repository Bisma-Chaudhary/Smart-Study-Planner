# Smart Study Planner

Overview

Smart Study Planner is a desktop application developed using "C# Windows Forms" and "SQL Server".
It helps students organize their academic work by managing subjects, tasks, deadlines, 
and study progress in one place. The application includes secure user authentication with multi-user support 
ensuring that each user can access and manage only their own data.
It is designed with a simple user-friendly interface to make study planning more efficient and organized.

# Features

1. User Registration & Login
2. Multi-user Support
3. Subject Management
4. Task Management
5. Calendar for Deadlines
6. Progress Tracking
7. Password Change

# Technologies Used

1. C#
2.  Windows Forms
3.SQL Server
4. ADO.NET
